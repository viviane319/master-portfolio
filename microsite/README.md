# Microsite

[`index.html`](index.html): "Community Signal Lab", a single-page personal site styled like a lab notebook on graph paper, in the Altarism palette.

- **Fig. 1:** a live three.js network of an org and its six communities, with messages flowing both ways. Drag to rotate.
- **§01 Readout:** headline numbers, each with its source.
- **§02 Jargon decompiler:** paste a mission statement to get a Flesch readability score, highlighted jargon and suggested swaps. It runs entirely in the browser, with no AI.
- **§03 Case files:** four pieces of work as context / input / delta.
- **§04 `git log --graph --career`:** the experience timeline drawn as version history.
- **§05 Periodic table:** skills and tools, filterable, each linked to where it was used.
- **§06 `man viv`:** approach and values as a Unix manual page, with a working mini terminal (try `help`).
- **§07 `ls -la`:** links to the rest of the portfolio.
- **⌘K / Ctrl+K:** a command palette for jumping anywhere.

It links to the PDFs and spreadsheet elsewhere in this repo, and uses `../assets/headshot.jpg` if present. three.js loads from cdnjs.
